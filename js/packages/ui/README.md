# @wizeworks/lens-ui

The [WizeLens](https://github.com/brandonkorous/wizelens) dashboard as a static build. Both add-ons serve it at `/_wizelens`:
`@wizeworks/lens-node` reads it from this package, and `WizeLens.AspNetCore` embeds it at build time.

You do not install this package yourself.
